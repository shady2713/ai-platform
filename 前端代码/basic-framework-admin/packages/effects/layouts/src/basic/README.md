## layout

### authentication

- 认证页 Logo 仅在提供点击处理器时呈现为原生按钮，保留键盘操作和焦点语义；纯展示场景不伪装成交互控件。
- 认证表单面板必须显式声明布局方向；版权区域仅在提供内容时以语义化 `footer` 渲染。

### global search

- 搜索入口、结果项和删除动作使用原生按钮；键盘事件仅在搜索弹窗打开时生效。
- 菜单、搜索和通知共用导航目标白名单：仅允许站内绝对路径或无凭据 HTTPS 外链。

### notification

- 有跳转目标的通知正文使用按钮，无目标项保持静态；已读和删除操作为独立并列控件，不嵌套交互元素。
- 通知跳转链接按不可信输入处理，只接受以 `/` 开头的站内绝对路径或无账号信息的 HTTPS 外链。
- 明文 HTTP、协议相对地址、任意相对路径、带账号信息的 URL 和非 HTTP(S) 协议默认拒绝。

### update check

- 版本检查使用单一轮询通道，仅在页面可见时运行；页面隐藏或组件卸载会中止在途请求。
- 用户取消刷新后将当前版本记为已知版本并恢复轮询，只有后续新版本再次提示。

### content spinner

- 内容区加载状态按实际导航实例追踪，重叠导航全部结束后才允许隐藏，且连续展示至少 500 毫秒。
- 新导航会取消旧的延迟隐藏任务；关闭加载偏好或卸载布局时立即清理状态、定时器和路由钩子。

### breadcrumb

- 可导航项使用原生按钮，当前项使用 `aria-current="page"` 的静态文本，不生成脚本伪链接。
- 动态路由使用当前参数解析实际站内路径；无法解析的项保持不可导航，选择事件仅接受经过统一白名单校验的站内绝对路径。

### header

- 支持通过 `header-right-n` 和 `header-left-n` 插槽扩展头部区域。
- `header-left-n` 预留区间：`0-19`，`breadcrumb` 建议使用 `21+`。
- `header-right-n` 预留区间：`0-49`；`global-search` 建议使用 `51-59`；`theme-toggle` 建议使用 `61-69`；`language-toggle` 建议使用 `71-79`；`fullscreen` 建议使用 `81-89`；`notification` 建议使用 `91-149`；`user-dropdown` 建议使用 `151+`。

### lock screen

- 锁屏只用于当前浏览器页面的临时隐私遮挡，不构成服务端身份认证或授权边界。
- 前端状态不保留锁屏口令原文，只保存带随机盐的 PBKDF2-SHA256 派生凭据；退出锁屏时立即清除。
- 返回登录入口执行正常的服务端会话退出流程。部署环境仍必须使用 TLS，并遵循服务端会话超时策略。
