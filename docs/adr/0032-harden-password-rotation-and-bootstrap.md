# ADR 0032：收紧改密与部署初始化边界

- 状态：已接受；登录审计事务条款由 [ADR 0036](0036-serialize-account-and-session-changes.md) 部分替代。

## 背景

仅强制首次改密不能阻止知道交付物初始口令的人抢先设置密码。旧密码验证与写入分离也允许并发请求覆盖已经变更的凭据；认证事务回滚会连带丢失失败日志。

## 决策

- 登录只使用账号密码及现有图形验证码、限流和失败锁定。高风险操作保留原有服务端权限与业务归属校验。
- 已发布迁移不改写。V41 删除废弃认证因素表，ADR 0017 随 MFA 移除一并废止；V42 只封存仍持有交付物固定摘要的种子账号。
- 种子账号默认禁用，由部署者通过 BOOTSTRAP_ADMIN_PASSWORD 提供独立口令后一次性激活；已激活账号不会被重启覆盖。激活后仍强制轮换初始口令。
- 首登改密以认证时读取的哈希、启用状态和强制改密标记作原子更新条件，更新失败不得撤销会话或清除失败次数。
- 当时的决策是登录审计使用独立事务保存；当前成功登录日志与会话签发同事务，失败审计独立提交，以 ADR 0036 为准。成功改密记录操作日志，重新认证成功后才记录登录成功。
- 新安装从空库执行完整 Flyway 链，默认禁止自动接管非空库；手工快照须按声明版本显式建立基线。

## 验证

单元测试覆盖初始化、禁用账号、旧哈希失效与会话撤销边界。真实数据库测试覆盖条件更新、失败审计留存、历史版本升级与快照基线；通过 integration 门禁执行。
