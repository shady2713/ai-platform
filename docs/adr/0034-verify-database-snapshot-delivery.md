# ADR 0034：验证手工快照与迁移链的交付一致性

- 状态：已接受

## 背景

手工快照的 bit 字面量错误会导致真实 MySQL 导入失败；版本注释、部署说明和迁移测试中的重复版本数字也会随新增迁移产生漂移。只比较表名和外键名不能证明两种建库路径具有相同字段和约束。

## 决策

- 已有 Flyway 迁移保持不可变，迁移链仍是数据库结构的权威来源。
- 快照文件头声明基线版本，操作文档引用该声明，contracts 门禁检查它与最新迁移一致。
- integration 门禁在同一版本 MySQL 中分别执行快照导入和空库迁移，比较表属性、字段类型与默认值、索引、外键动作、检查约束和关键认证种子。
- 快照只在显式建立所声明版本的基线后接管，后续迁移不得重放历史版本。升级测试从实际资源推导新增迁移数量。

## 验证

版本契约测试覆盖一致、落后、超前和声明缺失。`AuthenticationMigrationIT` 验证旧版本升级、独立种子口令保留、快照真实导入和建库路径一致性；这些测试属于阻断 CI 的 contracts 与 integration 门禁。
