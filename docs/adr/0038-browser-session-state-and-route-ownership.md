# 0038 — 浏览器会话状态与动态路由的生命周期

- 状态：采纳
- 日期：2026-09-08

## 问题

权限请求失败可能留下部分登录状态；退出后到达的旧请求可能重新写入令牌。动态路由只增加或覆盖会让新账号保留旧账号的页面注册。共享导航组件每次创建时注册的路由回调也没有释放路径。

## 决定

认证操作使用内存版本标识拒绝失效结果；刷新使用发起时的令牌确认当前会话仍然一致。退出先清除本地状态，且不因接口失败再次恢复 Cookie 会话。并发恢复共享请求；刷新队列中的每个请求只允许重试一次。登录失败清除尚未完成的本地会话；重新认证重新建立用户、权限及页面状态。

动态路由拥有明确的注册和注销边界，使用 Vue Router 返回的注销函数，退出或重新生成时全部释放。静态路由不属于会话，予以保留。导航时读取当前路由元信息，删除重复维护的缓存和永久回调。

## 验证

真实 Pinia 状态测试覆盖部分登录、退出接口失败、并发恢复和旧请求迟到；真实 Vue Router 测试验证旧账号路由注销、静态路由保留和生成期间退出。请求拦截器测试验证持续 401 不产生第二次刷新，也不使新账号失效。

浏览器状态管理不替代后端授权。后端仍在每次请求时校验会话和权限。
