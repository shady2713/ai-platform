# ADR 0044：精确限定密钥扫描的公开固定值

- 状态：已接受

## 决策

提交扫描将测试中的公开令牌和不可登录的 `!bootstrap-required` 封存标记误判为密钥。
保留 `scripts/secret-scan.sh` 入口，由 Node 实现暂存区扫描，以完整文件路径和完整字面量共同
限定例外。固定值清单仅由 `scripts/secret-scan.mjs` 持有，不整体排除测试目录或迁移文件。

同一行或同一文件中的其他凭据仍被拦截；新增固定值必须单独审查。扫描失败只输出文件路径，
不输出凭据。CI 的 Gitleaks 扫描保持独立。新增测试加入两个平台的 contracts 门禁。

## 验证

测试覆盖固定值路径限制、完整值限制、同一行多个赋值、环境变量引用与不完整赋值。
以实际暂存区验证提交扫描，公开固定值不再导致误报。
