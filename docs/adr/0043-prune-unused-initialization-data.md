# ADR 0043：精简无消费者的初始化数据

- 状态：已接受

## 依据与决策

当前操作日志以业务模块和动作字符串描述事件，旧 `infra_operate_type` 数字字典已无生产消费者。
V46 清理其 7 条原始字典值及空的类型记录，双端同时移除未使用的常量。

新安装只保留“总公司”根部门，种子管理员归属该部门；移除“深圳总公司”和“研发部门”两个示例。
迁移仅在管理员未激活、部门仍为原始三条记录、无其他用户、无部门范围分配且无会话时执行该收敛。
已使用或修改的组织保留；改过标签/状态或新增的字典值保留，其类型记录不删除。

保留管理员、超级管理员及授权关系、有效菜单、维护任务和仍有业务或扩展契约的字典。
会员与终端类型属于既有扩展契约，不因当前管理端没有直接页面而删除。
历史迁移保持不变，SQL 快照同步为 V46；本次不操作任何现有运行库。
全量字典比对同时发现旧快照遗漏了仍在使用的 S3 存储选项（id=1154）；按 V1 权威数据补回，
不能为了缩小初始化数据而删除有效存储后端的选项。

## 验证

真实 MySQL 集成测试覆盖空库终态、已激活账号和自定义数据保留，并比较快照与完整迁移链的
部门、管理员归属和全部字典数据。contracts 核对快照版本与结构，前端类型检查验证常量删除。
