# ADR 0029：移除未使用渠道与 UI 插件

- 状态：已接受

## 背景

部分短信渠道、UI 插件和登录端点没有生产消费者，也没有独立的能力契约。

## 决策

- 短信保留阿里云，移除腾讯云客户端、回调入口与渠道字典；历史渠道数据不作强制转换。
- 移除未使用的 echarts、code-editor 子路径，以及 col-page、content-wrap、count-to、ellipsis-text、json-viewer 组件。
- 移除短信登录端点及其专属枚举，保留忘记密码使用的短信验证码发送能力。

## 后果

删除对应依赖、测试和文档中的失效引用。验证码脱敏白名单继续由现存的短信场景枚举派生。
