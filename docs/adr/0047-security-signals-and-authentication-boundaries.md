# ADR 0047：安全指标结果语义与跨源认证隔离

状态：接受。

## 背景

审计发现跨源资源的 401 会触发管理端登出；安全计数器没有可抓取的导出入口，且会话撤销与账号锁定计数偏离实际结果。
门禁接线检查还把测试 import、脚本自引用和注释当作执行证据，无法拒绝同时移除两个 provider 调用的变更。

## 决策

- 请求客户端在认证响应处理前检查来源，外部 401 不刷新、入队或清除本站会话；跨源请求同时关闭凭据发送。
- Server 装配 Prometheus registry，端点使用独立、默认关闭的只读认证链。抓取凭据不能用于管理端，启用时配置错误在启动期失败。
- 保留会话撤销请求事件，新增携带实际删除数量的结果事件；指标监听结果事件并在提交成功后计数。
- Redis Lua 返回三种失败处理结果，避免通过非原子的前置锁查询推断锁定次数。
- check 门禁必须在两个 provider 中存在直接 node 调用，测试必须实际带 --test；注释和 import 不计入接线。

## 验证与边界

回归测试覆盖跨源 401、接线移除的红绿验证、真实 Prometheus 输出和默认拒绝访问、事务回滚与多会话数量。
真实 Redis 并发锁定与 MySQL 删除数量继续由 integration 门禁验证。
部署抓取与告警通知的接入步骤归属[部署文档](../deployment.md#2-健康检查与-actuator-暴露面)。
