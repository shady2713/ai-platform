# ADR 0035：授权判定读取当前数据库状态

- 状态：已接受

## 背景

“提交后删除缓存”不能阻止此前在途查询在删除之后回填旧值。角色、用户角色、菜单权限和部门范围使用这种缓存时，已撤销的权限可能再次生效，直到缓存过期。

## 决策

- 授权数据从数据库读取，移除安全相关的跨请求缓存键、重复缓存查询接口、失效注解和自代理依赖。
- 角色使用批量查询。部门层级由单次查询构建相邻节点关系后遍历，按编号去重，避免深层逐次查询和循环脏数据重复扫描；单次权限计算复用子树结果。
- 菜单授权同时要求自身及全部祖先启用。孤儿、循环及未知状态按无权限处理。
- 字典和展示模板缓存保留各自的一致性契约。数据库提交前已经开始的事务遵循数据库隔离语义，此决策不宣称撤回已经授权的在途操作。

## 验证

单元测试覆盖角色批量读取、菜单禁用祖先、未知状态、部门改挂及循环终止。真实 MySQL/Redis 测试在数据库变更后回填旧缓存值，再从公开服务接口验证读取结果仍反映数据库状态。
