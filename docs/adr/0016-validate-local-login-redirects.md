# ADR 0016：校验登录后的本地跳转目标

## 背景

管理后台会把目标路由放入登录页的 `redirect` 查询参数。该参数来自浏览器地址栏，属于不可信输入；直接解码和使用会使畸形百分号编码中断路由守卫，也可能把外部地址带入认证完成后的跳转流程。

## 决策

所有登录后跳转统一通过一个纯函数校验。目标必须是长度不超过 2048 个字符、以单个 `/` 开头的管理后台绝对路由，并拒绝协议相对地址、反斜杠、控制字符和无法解码的输入。校验失败时回退到调用方提供的安全本地路由；若回退值自身不安全，则使用 `/`。

路由守卫不得直接对查询参数调用 `decodeURIComponent` 后跳转。字典等非关键预加载失败必须被显式捕获和记录，不能产生未处理的 Promise 拒绝或阻断认证导航。

## 影响

- 外部站点不能借登录流程形成开放重定向。
- 畸形查询参数不会导致路由守卫异常。
- 合法的站内路径、查询串和片段仍可使用。
- 新增认证入口必须复用同一校验函数及其边界测试。
