# ADR 0026：源码规模与技术债标记进入阻断门禁

## 状态

已接受

## 背景

仓库已经声明逻辑文件不得超过 800 行，`TODO`、`FIXME`、`XXX` 必须携带负责人或问题引用，
但此前没有机械检查。规则只能依赖评审记忆，新增超大文件或无归属技术债不会让构建失败。
前端同时残留了 Playwright 配置例外，而项目已不再提供 Playwright/E2E 能力。

## 决策

- contracts gate 扫描 Git 已跟踪及未忽略的新逻辑源码，超过 800 行立即失败。
- 独立注释行中的技术债标记必须在同一行引用负责人、用户、数字 issue、项目 issue 编号或链接。
- 无脚本的 SVG Vue 图稿视为静态资产；其图形节点数量不参与逻辑源码行数约束。
- Windows 与 Linux Harness 同时运行检查器单元测试和仓库实扫。
- 删除 ESLint 中仅服务于已移除 Playwright 能力的配置例外。

## 影响

新增源码无法以未登记例外绕过规模和技术债归属要求，且跨平台 CI 行为一致。纯 SVG 图稿仍可
作为 Vue 静态组件存在，但一旦加入脚本逻辑就自动进入 800 行上限。现有业务行为和终端对接
预留不受影响。
