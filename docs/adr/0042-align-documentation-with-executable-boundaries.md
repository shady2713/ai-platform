# ADR 0042：文档按实际执行边界维护

- 状态：已接受

## 问题

入口文档把单项测试称为完整门禁，能力目录重复配置事实后未随实现更新，
部署手册混淆首次初始化与凭据轮换，并遗漏 Flyway 修复所需的完整迁移文件。

## 决策

- 完整验证通过已有 Harness 入口执行；根 README 说明门禁范围，模块文档链接该入口。
- 能力目录只保留模块职责与契约入口，配置、失败语义和清理责任归所属 README。
- 工程规则区分自动阻断项与人工评审目标，不改变现有门禁、阈值或测试范围。
- 数据库凭据轮换保留持久卷；迁移修复区分失败原因，使用原始迁移集及匹配版本工具。
- 历史 ADR 保留决策背景，被替代条款显式链接后续决策；无独立信息的占位文档删除。

## 验证边界

文档变更检查本地链接、命令语法和 contracts 门禁。凭据轮换与迁移恢复仍须在
隔离数据库演练，静态文档检查不代表生产恢复目标已达成。
