# ADR 0040：在数据库约束活跃用户联系方式唯一性

状态：接受

## 问题

手机号与邮箱只在服务中预查询，两个并发写入均可能通过检查。直接增加联系方式与删除标记的联合唯一键又会限制同一联系方式只能存在一条已删除记录，无法支持反复删除后复用。

## 决策

V45 将空白联系方式归一为 NULL，缺省值改为 NULL。函数唯一索引只索引未删除用户的非空、去除首尾空白后的联系方式；已删除用户映射为 NULL，不占用唯一性。邮箱继续采用列既有的不区分大小写排序规则。

原服务预查询提供友好提示，数据库约束裁决最终写入竞争。普通查询索引保留，用于现有手机号与邮箱等值查询。用户名原唯一约束不变。既有真实重复让迁移失败，迁移不得替用户选择联系方式归属或删除账号。

## 验证

`UserContactIntegrityIT` 验证默认缺失值、重复联系方式拒绝、大小写与空白语义、多次软删除后复用及并发分配仅一方提交。迁移测试验证已有重复数据阻断升级且保留原数据，快照对比包含函数索引表达式。
