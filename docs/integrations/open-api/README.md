# AI 中台开放 API 规范（应用端）

本目录是 AI 中台**开放端点**（`/app-api/ai/**`）的正式规范（O07 冻结已实现核心接口）。
管理端接口（`/admin-api/**`）不属于本规范，也不得出现在这里。

| 文件 | 说明 |
|---|---|
| `ai-open-api.json` | OpenAPI 3.1 规范：仅包含开放端点，含请求/响应示例与状态码 |
| `examples/` | 请求/响应与事件流夹具（`*.json` 与 SSE 样例），由契约测试按结构校验 |
| `README.md` | 接入方式、认证流程、错误语义与扩展流程 |

## 认证流程

1. 应用后端使用**客户端凭据**换取访问票据：`POST /app-api/ai/auth/ticket`（`appCode` + `appSecret`）。
   同一客户端连续失败会触发 429 节流；`token` **只在本次响应返回一次**，平台只保存摘要。
2. 后续开放端点使用 `Authorization: Bearer <ticket>`。票据对应**一个应用 + 一个主体**（USER/APP）。
3. 票据撤销、到期、应用停用或主体撤销后，请求按未认证处理（401）。
4. 归属判定一律使用票据解析出的主体：会话、运行与任务都按主体过滤，**越权与不存在同语义（404）**。

## 状态码语义

| 状态码 | 语义 |
|---|---|
| 200 | 成功（受理运行是"已受理"，`status=ACCEPTED`，尚未执行） |
| 400 | 入参不合法（长度、枚举、格式、Schema 等） |
| 401 | 未认证或票据无效（不存在/撤销/过期/应用或主体不可用同语义） |
| 403 | 已认证但缺少范围或权限 |
| 404 | 资源不存在或无权访问（同语义，防编号枚举） |
| 409 | 状态冲突、幂等键冲突、重放窗口过期、任务不可重试 |
| 429 | 超出配额或触发限流 |
| 502 / 503 / 504 | 上游（模型/连接器）失败 / 依赖不可用 / 上游超时（均为稳定错误，可重试） |

错误响应统一为 `{"code": <业务错误码>, "data": null, "msg": "..."}`，
业务错误码见 `docs/contracts/ai/error-code-map.md`。

## SSE 事件流

`GET /app-api/ai/run/events` 返回 `text/event-stream`：

- **先鉴权再开流**：归属判定失败按普通 HTTP 错误返回，不会开出匿名流；开流之后的错误以关闭订阅表达。
- 事件与 `docs/contracts/ai/run-event.schema.json`（RunEvent v1）一致，`seq` 由服务端并发安全分配。
- `afterSeq` 之后的事件按 `seq` 升序补发；**重放窗口过期**返回 409，此时请改用运行进度/快照续读，
  不要重新发起运行（受理幂等键会拒绝同键异请求）。
- 心跳是 SSE 注释（`: heartbeat`），**不推进 `seq`**：连接保活不等于运行有进展。
- 连接到期只关闭订阅（运行状态不变），客户端换票后按 `afterSeq` 续读。
- 样例见 `examples/run-events.stream.txt`。

## 公开文档的红线

- 不出现任何管理端路径（`/admin-api/**`）或管理端权限码。
- 不出现凭据、秘密、令牌摘要、连接串与模型输入正文；换票响应中的 `token` 是唯一例外，
  它只表示"签发一次"的语义（已在 Schema 描述中显式说明）。
- 结果引用只给标识与摘要（助手消息编号 + 正文摘要），正文通过会话接口按当前授权读取。
