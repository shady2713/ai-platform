# 数据分级与处理规则

本文是数据分级与处理规则的唯一权威。字段级契约见
`docs/contracts/field-catalog.yaml`。

## 分级

| 级别 | 定义 | 示例 |
|---|---|---|
| L1 公开 | 可公开披露 | 公开字典文案、公开菜单名称 |
| L2 内部 | 仅限组织内部，泄露造成有限损害 | 部门结构、操作类型、非秘密配置元数据 |
| L3 个人信息 | 可识别自然人 | 用户名、昵称、手机号、邮箱、头像、登录 IP/UA |
| L4 敏感数据或秘密 | 泄露可导致账号、系统或财产损害 | 密码哈希、Token、验证码及其校验凭证、客户端密钥、渠道密钥、数据源密码 |

## 强制处理规则

| 控制项 | L1 | L2 | L3 | L4 |
|---|---|---|---|---|
| 传输 | TLS | TLS | TLS | TLS |
| 存储 | 可明文 | 可明文 | 明文且最小权限，按目的限制保留期 | 不需恢复的值使用抗暴力哈希或不可逆摘要；需恢复的值使用带版本的 AES-GCM 密文 |
| 日志/指标 | 可记录 | 最小化记录 | 默认禁入，确需时掩码 | 禁入正文、异常参数、标签和对象 `toString()` |
| API 响应 | 可返回 | 按权限返回 | 最小字段并按场景脱敏 | 默认禁出；凭证只在创建或轮换成功时向授权调用方返回一次 |
| 导出 | 允许 | 需审计 | 需审批、最小字段和审计 | 禁止通用导出 |
| 审计 | 可选 | 必须 | 必须 | 必须，且普通管理员不可修改 |

## 实现不变量

- 用户密码使用自描述强哈希；访问令牌和刷新令牌只以 SHA-256 摘要写入 MySQL，不在 Redis 保存会话副本。授权与会话存储边界见 [ADR 0036](../adr/0036-serialize-account-and-session-changes.md)。
- 短信渠道密钥和文件存储凭据等必须恢复的 L4 值统一通过 security
  starter 的 `CredentialCipher` 保存为随机 nonce、业务上下文 AAD 的 AES-GCM
  版本化密文；生产主密钥只允许由部署 Secret 注入。
- 管理端查询只返回凭据是否已配置，创建后不再回显明文；更新请求留空表示保留
  已有凭据，显式轮换才覆盖密文。
- access token 只驻留浏览器页面内存；refresh token 只存在 host-only、`HttpOnly`、
  `SameSite=Strict` Cookie，生产环境强制 `Secure`。
- 访问日志和异常日志统一经过敏感字段清理；L3 直接联系方式（手机号、电话、邮箱）与 L4 字段默认删除，已路由请求只记录服务端路由模板、未路由请求只记录固定标识，解析失败只能记录固定占位内容。
- JSON 解析失败只记录输入类型/长度、目标类型和异常类名；禁止记录 Jackson 原始异常正文，也不得把可能携带输入片段的原始异常链继续向上游传播。
- 捕获异常需要保留诊断堆栈时统一使用 `SafeExceptionLogUtils.format`：保留异常类型和栈帧，删除异常正文并限制因果链深度与总长度。生产代码禁止向日志框架直接传入捕获的异常对象，也禁止在 catch 块读取 `getMessage()`、`getLocalizedMessage()` 或根因正文后写入日志、数据库、接口响应或新异常；业务异常通过 `ServiceException.getPublicMessage()` 显式跨越公开边界，校验异常通过约束对象提取声明文案。`scripts/check-safe-exception-handling.mjs` 在 contracts 门禁中阻止新增违规。
- 本地与测试 profile 的 MyBatis DEBUG 日志必须逐 Mapper 排除 L4 参数：认证、会话、用户、短信渠道、短信验证码和短信日志 Mapper 均使用 `INFO`。
- 登录和重置密码验证码在发送至供应商前可短暂存在于内存或队列；`system_sms_log` 的正文与 `code` 参数必须保存为 `[REDACTED]`，不得保留明文验证码。
- 含凭据、L4 字段或 L3 直接联系方式的 Lombok `@Data` 对象必须以 `@ToString.Exclude` 或类级 `exclude` 排除；认证、短信、会话、文件上传与渠道凭据，以及手机号、电话、邮箱由 `scripts/check-sensitive-tostring.mjs` 在 contracts 门禁中机械校验。短信对象还必须排除手机号、IP、验证码、短信正文、模板参数及供应商错误详情。
- 带 `@DiffLogField` 的 L3 直接联系方式必须通过脱敏解析函数写入操作审计；差异判定保留原值，审计展示只保留掩码，`scripts/check-sensitive-diff-log.mjs` 在 contracts 门禁中机械校验。
- 动态参数表不得承载 L4 值。任何新增 L3/L4 字段必须同时定义目的、访问者、
  保留期、删除/匿名化方式和日志策略。
