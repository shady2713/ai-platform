# basic-framework-biz-ip

IP 地址与行政区划查询工具组件（纯工具库，无 auto-configuration）。资源文件随
jar 发布，不依赖外部查询服务。

## 提供的能力

- `IPUtils` 使用内置 `ip2region.xdb` 查询 IP 所属区域。
- `AreaUtils` 使用内置 `area.csv` 查询行政区划及层级关系。
- `AreaConvert` 提供行政区划文本与结构化值的 Excel 转换。

## 使用约束

- 查询结果只用于区域展示或业务辅助判断，不作为可信身份、授权或精确定位依据。
- 更新区域数据时必须同步更新对应测试；不得在业务模块复制资源文件或另建静态缓存。
- 无法解析的 IP 或行政区划必须返回明确的空结果，不得猜测或静默映射到默认地区。

## 验证

模块单元测试覆盖资源加载、正常查询、非法输入和未知区域分支，并由后端 JaCoCo 棘轮阻断覆盖率下降。
